## Los datos no están versionados

El `.gitignore` excluye `*.csv`, `*.ndjson` y `*.geojson`. Cada laboratorio documenta en su propio README qué archivos hay que dejar en la carpeta antes de correr los notebooks, y cuáles se generan solos.

## Requisitos

- Python 3.11+ con `pandas`, `matplotlib` y `jupyter`
- Docker (se usa durante todo el semestre — conviene verificar `docker run hello-world` antes de la primera sesión)

## Versión docente

Los notebooks `*_docente.ipynb` traen las soluciones resueltas y las respuestas esperadas. **No distribuir a los equipos** — este repositorio es privado por esa razón.
